# Buy-U Analytics Metric Definitions

All metrics use exact integer sen for monetary calculations, Malaysian timezone (`Asia/Kuala_Lumpur`, UTC+8) for date windows (`7d`, `30d`, `90d`, `this_month`, `all`, `custom` inclusive full MYT days), paginated full-table loading (`fetchAllPaginated` in 1,000-row chunks so Supabase row limits never silently truncate totals), and authoritative payment verification (`isAuthoritativeOrderPaymentVerified`). No historical events are fabricated prior to activation.

| Metric | Source Tables | Calculation | Inclusion / Exclusion | Denominator / Edge Case | Role Access |
| --- | --- | --- | --- | --- | --- |
| **Gross Verified Product Sales** | `orders`, `checkout_sessions`, `payments` | `SUM(orders.subtotal_sen)` | Verified paid orders only; excludes unpaid/expired/cancelled and RM 1.00 FPX fee; never double-counts parent checkout vs child orders | N/A | Seller (own), Admin (all) |
| **Net Product Sales** | `orders`, `order_refunds` | `Gross Verified Sales - SUM(succeeded refund_amount_sen)` | Deducts executed (`succeeded`) simulated refunds only | N/A | Seller (own), Admin (all) |
| **Category / Product Net Sales (Multi-Item Orders)** | `orders`, `order_items`, `order_refunds` | `ROUND(netOrderSen * (lineGrossSen / orderItemsGrossSum))` | Proportional attribution across multi-item orders and order-level refunds so category/product sums reconcile cleanly against net sales | Falls back to `0` if `orderItemsGrossSum === 0` | Seller (own), Admin (all) |
| **Net Platform Commission (2%)** | `orders`, `order_refunds` | `SUM(commission_sen) - SUM(succeeded commission_reversal_sen)` | Excludes ToyyibPay RM 1.00 FPX fee (not platform profit) | N/A | Seller (own), Admin (all) |
| **Net Seller Earnings (Pre-Expense)** | `orders`, `order_refunds` | `SUM(seller_net_sen) - SUM(succeeded seller_deduction_sen)` | Explicitly labeled pre-expense (never called "profit") | N/A | Seller (own), Admin (all) |
| **Period Growth %** | Selected window vs equal-length prior window | `((current - previous) / previous) * 100` | MYT window boundaries (`7d`, `30d`, `90d`, `this_month`, `custom`) | Returns `null` (`N/A`) when `previous === 0` or `range === 'all'` | Seller, Admin |
| **Measured Active Users & Daily Trend** | `orders`, `listing_views`, `service_requests`, `free_notice_claims`, `profiles.last_active_at` | Period total = distinct user IDs across dated events + `last_active_at`; daily trend reconstructed strictly from dated events (`paid_at`, `viewed_at`, `created_at`) | NEVER counts dormant accounts merely because `profiles.status = 'active'` | Tracking of `listing_views` & `last_active_at` begins at Phase 8F activation | Admin only |
| **Listing Views & Conversion %** | `listing_views`, `orders`, `order_items` | Daily deduplicated `(viewer_id, listing_id, view_day)` excluding seller self-views; `MIN(100, (uniquePurchasers / uniqueViewers) * 100)`; `ordersPerViewer` tracked separately | Published listings only; uses compatible `uniquePurchasers` / `uniqueViewers` cohorts so conversion never exceeds `100%` | Returns `null` (`N/A`) when `uniqueViewers === 0` | Seller (own), Admin (all) |
| **Student Business Sellers** | `listings`, `orders`, `order_items` | Strictly `listings.kind = 'business'` (food businesses already store `kind = 'business'` with `is_food = true`; never classifies non-business listings by `is_food`) | Separated from `pre_loved` sellers, `service` providers, and `free_notices` donors; multi-item orders attributed proportionally | N/A | Admin only |
| **First-Time Successful Sellers** | `orders` (verified completed all-time) | Count of sellers whose earliest-ever verified `completed` order timestamp falls inside the selected window | Verified completed orders only; excludes sellers who completed an earlier order before window start | `0` when no new sellers completed their first order in window | Admin only |
| **Completed Donations & Units** | `free_notices` (`active`/`closed`), `free_notice_claims` | `COUNT` & `SUM(quantity)` where `claim.status = 'collected'` | Excludes merely posted, requested, reserved, expired, or cancelled claims; zero fabricated CO2/environmental estimates | N/A | Public aggregate, Admin |
| **Open Reports** | `reports` | `COUNT` where `status IN ('submitted', 'under_review')` | Uses hosted `reports` canonical initial status `'submitted'` | Excludes `'resolved'` and `'dismissed'` | Admin only |
| **Verified Rating** | `reviews` | `AVG(rating)` where `hidden = false` | Completed verified orders (**Verified Purchase**) or completed service requests (**Verified Service**) only | `null` ("No reviews yet") when `count === 0` — NEVER `5.0` | Public |
